Knowledge base articles are written by athletes, coaches, judges, organizers, and developers. You can submit an article in two ways, via GitHub or by email, and the formatting rules are the same for both.

## Who can become an author

Anyone who wants to write a useful text: a coach with a method, an athlete with experience, a developer who understands shooting technology.

## What you can write about

| Topic               | Examples                                              |
| ------------------- | ----------------------------------------------------- |
| Training            | Plans, diaries, mistake analyses                      |
| Exercises           | Breakdowns, tips on performing them                   |
| Weapons             | Reviews, setup, zeroing, maintenance                  |
| Anti-doping         | Personal experience, rule breakdowns, getting a certificate |
| Competitions        | Preparation, reports, analytics                       |
| Psychology          | Mindset, concentration, dealing with nerves           |
| Nutrition and routine | What works for you personally                       |

The text should be useful and verifiable. Choose the article type and length from the table in `STYLE_GUIDE.md`.

## How to submit an article

### Via GitHub

This way suits you if you have worked with Git or want to learn. All materials are in the open repository [ShotSCOPE-wiki](https://github.com/NotDoneByOne/ShotSCOPE-wiki).

1. Sign up at [github.com](https://github.com) if you don't have an account, and fork the repository (`Fork`).
2. Read `CONTRIBUTING.md`, `STYLE_GUIDE.md`, and `TEMPLATES.md` in the repository root.
3. Add your article to the `content/` folder using the template for its type: in an existing section or in a new folder.
4. Add the English version to `content/en/` or note in the Pull Request that the translation will follow.
5. Run `npx wiki build`; the build must pass without errors.
6. Create a Pull Request using the repository template. We will see your submission and get in touch.

If something goes wrong, we will help you sort it out.

### By email

This way needs no registration. Publication takes longer because editors review the piece manually.

1. Write your article in any format: a document (Word, Google Docs), an email with the text, or an Obsidian note.
2. Add photos, screenshots, or videos if you have any.
3. Send everything to [notdonebyone@internet.ru](mailto:notdonebyone@internet.ru).

In the email, include the name for the byline, the title of the piece, and, optionally, a few words about yourself and a link to your social media or website. We will read the piece, ask questions if needed, help with formatting, and send you a link to the finished article.

## What we check before publication

| Rule        | Explanation                                                |
| ----------- | ---------------------------------------------------------- |
| Accuracy    | Facts are verifiable, especially on anti-doping and rules  |
| Respect     | No insults, aggression, or incitement                      |
| Usefulness  | The text helps other athletes                              |
| Originality | Real experience instead of copying                         |

If you have doubts, send it anyway; we will discuss it and help you improve it.

## What the author gets

A byline and a link to your social media or website, editing help, and a part in the app's development: authors' ideas may become the basis of new features.

## Questions and answers

### Can I write anonymously?

Yes, you can sign with a pseudonym or nickname.

### Do I need to know programming?

No. The email way needs no technical skills.

### How much do authors get paid?

For now ShotSCOPE is a non-commercial project: publications are free for both readers and authors.

### Can I publish other people's texts?

Only if you are the author and give permission to publish. Copying other people's materials without consent is not allowed.

### How quickly is an article published?

Usually within 3–7 days of receipt. If it's urgent, say so in your email.
