Справочник дисциплин вырос с 7 до 23 упражнений по правилам ССР, а для каждой новой дисциплины уже заведены нормативы разрядов. База знаний открывается прямо в приложении, появился английский язык. Обновление бесплатное, все записи сохраняются.

## Новое

### Дисциплины

**16 новых упражнений неподвижной мишени.** Винтовка: ВП-20, ВП-30, ВП-40, МВ-30, МВ-60, МВ-3x40. Пистолет: ПП-20, ПП-30, ПП-40, МП-20, МП-30СС, МП-60СС, МП-60М, МПП-30, МПП-40, КП-60. Все они в **Профиль → Дисциплины**.

**Нормативы разрядов по ЕВСК 2026.** У новых дисциплин есть нормы МСМК, МС, КМС и I–III разрядов для мужчин и женщин. Приложение сверяет с ними результат так же, как для остальных дисциплин.

**Этапы в многоэтапных упражнениях.** МВ-3x40 и МВ-3x20 разбиты на этапы с колена, лёжа и стоя, КП-60 — на МП-30 и МП-30С. Этапы видны в карточке дисциплины.

**Пистолет центрального боя.** Для КП-60 появился новый тип оружия — **Пистолет (ЦБ)**. Его можно выбрать при добавлении оружия.

### База знаний в приложении

Статьи wiki.shotscope.ru открываются внутри приложения, без перехода в браузер. Есть структура разделов, поиск и оглавление статьи. Прочитанные статьи доступны без интернета.

### Английский язык

Интерфейс можно переключить на английский: **Профиль → Настройки → Язык интерфейса**. По умолчанию приложение берёт язык системы.

### Список выстрелов на мишени

На экране мишени выстрелы собраны в боковую шторку: балл, номер и данные выстрела видны, не уходя с мишени.

## Изменено

**Оформление.** Светлая тема стала слоистой: серая страница, белые карточки, мягкие тени. Верхняя панель полупрозрачная, а нижний край экрана плавно уходит в градиент.

**Заставка при запуске.** Новая видео-заставка в светлой и тёмной теме.

**QR-код тренера.** Ссылка из QR ведёт на shotscope.ru и сразу открывает приложение, если оно установлено.

**Серийный номер оружия.** Без серийного номера оружие не сохранится — приложение подскажет, что поле нужно заполнить.

**Отчёты о сбоях.** Если приложение падает, оно отправляет обезличенный технический отчёт. Почта и токены входа в отчёт не попадают. Это помогает быстрее находить ошибки.

## Исправлено

**Десятка засчитывалась как девятка.** Справочник колец восстанавливается сам, а очки уже сохранённых выстрелов, серий и событий пересчитаны.

**Мишень для МП-60.** В сессиях МП-60 снова можно добавить мишень — раньше кнопка не срабатывала.

**Пустая сессия без объяснений.** Если в сессии нет мишеней, приложение говорит почему.

**Нижняя панель навигации.** Больше не пропадает при прокрутке.

**Номера на мишени.** Цифры колец стоят по центру, кнопки масштаба не перекрывают мишень.
