Статьи базы знаний пишут спортсмены, тренеры, судьи, организаторы и разработчики. Предложить статью можно двумя способами: через GitHub или по почте, а правила оформления одни для обоих.

## Кто может стать автором

Любой, кто хочет написать полезный текст: тренер с методикой, спортсмен с опытом, разработчик, который разбирается в технологиях стрельбы.

## О чём можно писать

| Тема                | Примеры                                           |
| ------------------- | ------------------------------------------------- |
| Тренировки          | Планы, дневники, разборы ошибок                   |
| Упражнения          | Разбор, советы по выполнению                      |
| Оружие              | Обзоры, настройка, пристрелка, уход               |
| Антидопинг          | Личный опыт, разбор правил, получение сертификата |
| Соревнования        | Подготовка, отчёты, аналитика                     |
| Психология          | Настрой, концентрация, работа с волнением         |
| Питание и режим     | Что работает лично у тебя                         |

Текст должен быть полезным и проверяемым. Тип статьи и объём выбери по таблице в `STYLE_GUIDE.md`.

## Как предложить статью

### Через GitHub

Способ для тех, кто работал с Git или хочет научиться. Все материалы лежат в открытом репозитории [ShotSCOPE-wiki](https://github.com/NotDoneByOne/ShotSCOPE-wiki).

1. Зарегистрируйся на [github.com](https://github.com), если нет аккаунта, и сделай форк репозитория (`Fork`).
2. Прочитай `CONTRIBUTING.md`, `STYLE_GUIDE.md` и `TEMPLATES.md` в корне репозитория.
3. Добавь статью в папку `content/` по шаблону нужного типа: в существующий раздел или в новую папку.
4. Добавь английскую версию в `content/en/` или напиши в Pull Request, что перевод будет позже.
5. Выполни `npx wiki build`: сборка должна пройти без ошибок.
6. Создай Pull Request по шаблону репозитория. Мы увидим заявку и свяжемся с тобой.

Если что-то пойдёт не так, поможем разобраться.

### По почте

Способ без регистрации. Публикация займёт больше времени: материал проверяют редакторы вручную.

1. Напиши статью в любом формате: документ (Word, Google Docs), письмо с текстом или заметка в Obsidian.
2. Добавь фото, скриншоты или видео, если они есть.
3. Отправь всё на [notdonebyone@internet.ru](mailto:notdonebyone@internet.ru).

В письме укажи имя для подписи, заголовок материала и, по желанию, пару слов о себе и ссылку на соцсети или сайт. Мы прочитаем материал, при необходимости зададим вопросы, поможем с оформлением и пришлём ссылку на готовую статью.

## Что мы проверяем перед публикацией

| Правило        | Пояснение                                                  |
| -------------- | ---------------------------------------------------------- |
| Достоверность  | Факты проверяемы, особенно про антидопинг и правила        |
| Уважение       | Без оскорблений, агрессии и разжигания                     |
| Польза         | Текст помогает другим спортсменам                          |
| Оригинальность | Живой опыт вместо копирования                              |

Сомневаешься — всё равно присылай, обсудим и поможем доработать.

## Что получает автор

Подпись под статьёй и ссылку на соцсети или сайт, помощь в редактуре и участие в развитии приложения: идеи авторов могут стать основой новых функций.

## Вопросы и ответы

### Можно ли писать анонимно?

Да, можно подписаться псевдонимом или никнеймом.

### Нужно ли уметь программировать?

Нет. Для способа по почте технические навыки не нужны.

### Сколько платят авторам?

Пока ShotSCOPE — некоммерческий проект: публикации бесплатны и для читателей, и для авторов.

### Можно ли публиковать чужие тексты?

Только если ты их автор и даёшь разрешение на публикацию. Копировать чужие материалы без согласия нельзя.

### Как быстро выходит статья?

Обычно за 3–7 дней после получения. Если срочно, напиши об этом в письме.
