Теги группируют статьи по темам: от упражнений и типов оружия до уровней подготовки. Выбери тег, чтобы увидеть все статьи с ним.

## Как пользоваться тегами

| Действие                        | Результат                                  |
| ------------------------------- | ------------------------------------------ |
| Нажать на тег ниже или в статье | Открыть все материалы по этой теме         |
| Поиск (⌘+K)                     | Найти материалы по ключевым словам         |
| Ссылка на страницу тега         | Формат: `[[tags/название-тега]]`           |

Сайт сам создаёт страницу для каждого тега и поддерживает вложенные теги, например `оружие/винтовки` или `тренировки/ошибки`.

## Вложенные теги

Вложенные теги группируют материалы точнее. У каждого уровня своя страница тега.

- `оружие/винтовки/пневматика`
- `оружие/винтовки/малокалиберные`
- `оружие/пистолеты/скорострельные`
- `оружие/пистолеты/произвольные`
- `тренировки/упражнения/изготовка`
- `тренировки/упражнения/спуск`
- `тренировки/упражнения/дыхание`
- `соревнования/подготовка/разминка`
- `соревнования/подготовка/экипировка`

Примеры страниц: [[tags/оружие]] — всё об оружии, [[tags/оружие/винтовки]] — только о винтовках, [[tags/оружие/винтовки/пневматика]] — только о пневматических винтовках.

## Как добавить новый тег

1. Укажи тег в заметке: `tags: [новый-тег]` в frontmatter.
2. Сайт создаст страницу тега при следующей сборке.
3. Чтобы настроить страницу тега, создай файл `content/tags/новый-тег.md`.
