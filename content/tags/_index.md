# 🏷️ Все теги проекта

**Теги** — это быстрый способ ориентироваться в базе знаний ShotSCOPE SPM. Каждый материал помечен ключевыми словами, которые помогают группировать связанные темы: от конкретных упражнений до типов оружия и уровней подготовки.

На этой странице собраны **все теги**, которые используются в проекте. Просто выберите интересующий — и вы увидите все заметки с этим тегом.

> 💡 Quartz автоматически создаёт отдельную страницу для каждого тега и поддерживает вложенные иерархии (например, `оружие/винтовки` или `тренировки/ошибки`).

---

## 🔍 Как пользоваться тегами

| Действие                            | Результат                                             |
| ----------------------------------- | ----------------------------------------------------- |
| **Кликнуть на тег ниже**            | Перейти на страницу со всеми материалами по этой теме |
| **Кликнуть на тег в любой заметке** | Увидеть все связанные материалы                       |
| **Использовать поиск (⌘+K)**        | Найти материалы по ключевым словам                    |
| **Ссылаться на страницу тега**      | Формат: `[[tags/название-тега]]`                      |

## 🌳 Иерархические теги

Quartz поддерживает **вложенные теги** — они позволяют группировать материалы ещё точнее:

- `оружие/винтовки/пневматика ` 
- `оружие/винтовки/малокалиберные`
- `оружие/пистолеты/скорострельные`  
- `оружие/пистолеты/произвольные`

- `тренировки/упражнения/изготовка`  
- `тренировки/упражнения/спуск`  
- `тренировки/упражнения/дыхание`

- `соревнования/подготовка/разминка`  
- `соревнования/подготовка/экипировка`


Каждый уровень иерархии имеет **собственную страницу тега**. Например:
- [[tags/оружие]] — всё об оружии
- [[tags/оружие/винтовки]] — только о винтовках
- [[tags/оружие/винтовки/пневматика]] — только о пневматических винтовках

## ✍️ Как добавить новый тег

Если вы **автор проекта** и хотите добавить новый тег:

1. Просто используйте его в заметке: `tags: [новый-тег]` в frontmatter
2. Quartz **автоматически создаст** страницу для этого тега при следующей сборке
3. Для кастомизации страницы тега создайте файл `content/tags/новый-тег.md`
