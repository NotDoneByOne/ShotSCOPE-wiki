# Шаблоны для создания контента

## 📋 Метаданные страницы (Frontmatter)

В начале каждой статьи (до основного текста) можно указывать специальные настройки в блоке, обрамленном `---`. Это называется **frontmatter**. Quartz использует эти настройки для управления тем, как страница отображается и индексируется.

### Основные атрибуты, которые поддерживает Quartz

| Атрибут | Псевдонимы (алиасы) | Тип данных | Описание | Пример |
|---------|---------------------|------------|----------|---------|
| `title` | — | строка | Заголовок страницы. Если не указан, Quartz использует имя файла. | `title: "Как настроить прицел"` |
| `description` | — | строка | Краткое описание страницы. Используется в превью при ссылках (в соцсетях, поисковиках). | `description: "Пошаговая инструкция по настройке оптики для начинающих"` |
| `draft` | — | boolean (`true`/`false`) | Черновик. Если `true`, страница НЕ публикуется на сайте. | `draft: false` |
| `publish` | — | boolean | Альтернатива `draft`. Некоторые темы используют его. | `publish: true` |
| `date` | `created`, `publishDate` | дата | Дата создания или публикации. Формат: ГГГГ-ММ-ДД. | `date: 2024-06-15` |
| `modified` | `lastmod`, `updated` | дата | Дата последнего изменения. | `modified: 2024-06-20` |
| `tags` | `tag` | список строк | Теги для категоризации страницы. Подробнее см. ниже. | `tags: [оружие, оптика, настройка]` |
| `aliases` | `alias` | список строк | Другие имена страницы. По ним тоже можно будет найти статью. | `aliases: [пристрелка, zeroing]` |
| `permalink` | — | строка | Постоянная ссылка на страницу. Если указать, URL не изменится даже при переименовании файла. | `permalink: /guides/scope-zeroing` |
| `enableToc` | — | boolean | Показывать оглавление страницы (Table of Contents) или нет. | `enableToc: true` |
| `cssclasses` | `cssclass` | строка или список | Дополнительные CSS-классы для стилизации конкретной страницы. | `cssclasses: [wide-page, spotlight]` |
| `socialDescription` | — | строка | Отдельное описание для соцсетей (если нужно отличаться от основного `description`). | `socialDescription: "Секреты пристрелки от чемпионов"` |
| `socialImage` | `image`, `cover` | строка | Путь к картинке для превью в соцсетях. | `socialImage: /static/images/scope-preview.jpg` |

### 📌 Как правильно работать с тегами

Теги — это мощный инструмент навигации. Quartz автоматически создает страницы для каждого тега, где собираются все статьи с этим тегом.

**Синтаксис:**

```yaml
tags:
  - тег1
  - тег2
  - тег3
```

или в одну строку: `tags: [тег1, тег2, тег3]`

#### Правила и рекомендации:

**Иерархия тегов.** Можно использовать слеш `/` для создания вложенности. Quartz создаст страницы для каждого уровня.
Пример: `спортсменам/психология` — появятся страницы для тега спортсменам и для тега `спортсменам/психология`.

**Единообразие.** Старайтесь использовать одинаковые формулировки для одних и тех же тем.
- ✅ `оружие/пистолет`
- ✅ `оружие/винтовка`
- ❌ `пули`, `патроны`, `боеприпасы` (лучше выбрать один вариант, например `снаряжение/патроны`)

**Регистр.** Quartz автоматически приводит теги к нижнему регистру в URL, но в самом файле можно писать как удобно. Рекомендуем использовать нижний регистр для единообразия.

**Спецсимволы.** Избегайте пробелов и спецсимволов кроме дефиса - и слеша /. Пробелы заменяйте на дефисы.
- ✅ `звуковой-тренажер`
- ❌ `звуковой тренажер`

**Описание страницы тега.** Quartz позволяет добавить описание для страницы конкретного тега. Для этого создайте файл `content/tags/название-тега.md` с таким содержимым:

```markdown
---
title: "Название раздела тегов"
description: "Описание того, что объединяют эти статьи"
---

Здесь можно написать введение для этого раздела тегов.
```

Например, для тега `оружие/оптика` файл будет `content/tags/оружие/оптика.md`.

### ✨ Пример полного блока frontmatter

```markdown
---
title: "Звуковой тренажер: полное руководство"
description: "Как использовать звуковой тренажер ShotSCOPE для отработки скоростной стрельбы где угодно"
date: 2024-06-01
modified: 2024-06-10
tags:
  - shotscope
  - функции
  - тренажер
  - звуковой-тренажер
  - спортсменам/тренировки
aliases: [метроном, audio-trainer]
enableToc: true
draft: false
---
```

## 🎯 Шаблоны статей

Чтобы база знаний выглядела единой и профессиональной, используйте эти шаблоны при создании новых страниц. Просто копируйте код и заполняйте своим текстом.

### 1. Шаблон «Релиз (Release Notes)»

**Где использовать:** В папке `ShotSCOPE/Releases/` при выходе новой версии приложения.
**Цель:** Кратко и понятно рассказать пользователям, что нового, и поблагодарить их.

```markdown
---
title: 'Версия {{Версия}} — {{Короткое название релиза}}'
date: {{Дата в формате ГГГГ-ММ-ДД}}
tags: [release, обновление, фичи, shotscope]
---

Привет, друзья! 👋

Мы вернулись с обновлением. Спасибо всем, кто писал нам в обратную связь — Ваши идеи стали основой для этого релиза.

## 🚀 Что нового?

### {{Название первой фичи}}
{{Описание. Что это такое, зачем нужно и как этим пользоваться.}}

### {{Название второй фичи}}
{{Описание.}}

## 🛠 Исправления и улучшения

*   Исправлена ошибка, из-за которой {{кратко описание бага}}.
*   Улучшена {{что-то стало работать быстрее/удобнее}}.

## ⬇️ Как получить обновление?

Обновление уже доступно в RuStore. Просто зайдите в магазин приложений и нажмите «Обновить».

Спасибо, что Вы с нами! Продолжаем делать ShotSCOPE лучше вместе. 🚀

---
*Автор: Команда ShotSCOPE*
```

### 2. Шаблон «Справочная статья»

**Где использовать:** В любом разделе (`Спортсменам`, `Тренерам`, `Правила` и т.д.).
**Цель:** Дать структурированную, полезную информацию, которую можно изучать и на которую можно ссылаться.

```markdown
---
title: '{{Заголовок статьи}}'
date: {{Дата в формате ГГГГ-ММ-ДД}}
tags: [{{тег1}}, {{тег2}}]
description: {{Краткое описание для превью}}
---

# {{Заголовок статьи}}

{{Вступительный абзац. Кратко объясните, о чем пойдет речь и почему это важно.}}

## {{Название первого раздела}}

{{Текст раздела. Используйте списки и выделения, где это уместно.}}

*   {{Пункт первый}}
*   {{Пункт второй}}

## {{Название второго раздела}}

{{Текст раздела. Если нужно, добавьте пример:}}

> [!example] Пример из жизни
> {{Опишите конкретную ситуацию, как это знание применяется на практике.}}

## Совет от команды ShotSCOPE

{{Короткий практичный совет, возможно, с отсылкой к функционалу приложения.}}

---
*Автор: {{Ваше имя или псевдоним}}*
```

### 3. Шаблон «Статья-инструкция (How-to)»

**Где использовать:** Для пошаговых руководств (например, «Как добавить оружие в приложение»).
**Цель:** Провести пользователя по шагам от точки А к точке Б.

```markdown
---
title: 'Как {{сделать что-то}}'
date: {{Дата}}
tags: [инструкция, how-to, shotscope]
description: {{Пошаговое руководство по...}}
---

# Как {{сделать что-то}}

{{Краткое введение: зачем это нужно делать.}}

## Что Вам понадобится

*   {{Необходимое условие 1 (например, установленное приложение)}}
*   {{Необходимое условие 2}}

## Пошаговая инструкция

1.  **Откройте раздел «{{Название раздела}}».**
    {{Пояснение к шагу, если нужно.}}
2.  **Нажмите на кнопку «{{Название кнопки}}».**
    {{Пояснение.}}
3.  **Заполните поля:**
    *   `Поле 1`: {{Что сюда писать}}.
    *   `Поле 2`: {{Что сюда писать}}.
4.  **Нажмите «Сохранить».** Готово!

> [!tip] Совет
> {{Хитрость, которая упростит процесс.}}

---
*Автор: Команда ShotSCOPE*
```
