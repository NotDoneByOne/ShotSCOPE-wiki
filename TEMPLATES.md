# Шаблоны для создания контента

## Метаданные страницы (Frontmatter)

В начале каждой статьи (до основного текста) можно указывать специальные настройки в блоке, обрамленном `---`. Это называется **frontmatter**. Правила оформления самих статей — в [`STYLE_GUIDE.md`](STYLE_GUIDE.md). Генератор сайта использует эти настройки для управления тем, как страница отображается и индексируется. Два атрибута обязательны для каждой статьи: `lang` и `translationKey` (без них сборка падает).

### Основные атрибуты

| Атрибут             | Псевдонимы (алиасы)      | Тип данных                    | Описание                                                                                                                          | Пример                                                                   |
| ------------------- | ------------------------ | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `lang`              | —                        | `ru` или `en`                 | **Обязательно.** Язык статьи; должен совпадать с папкой (всё под `content/en/` — `en`, остальное — `ru`).                         | `lang: ru`                                                               |
| `translationKey`    | —                        | строка (kebab-case, латиница) | **Обязательно.** Общий для всех языковых версий одной статьи; по нему работает переключатель RU/EN.                               | `translationKey: shotscope-faq`                                          |
| `title`             | —                        | строка                        | Заголовок страницы. До 60 знаков, без точки и эмодзи; совпадает с тем, что ищет читатель. Если не указан, используется имя файла. | `title: "Как настроить прицел"`                                          |
| `description`       | —                        | строка                        | Одно предложение до 160 знаков, не повторяет `title`. Используется в превью при ссылках (в соцсетях, поисковиках).                | `description: "Пошаговая инструкция по настройке оптики для начинающих"` |
| `draft`             | —                        | boolean (`true`/`false`)      | Черновик. Если `true`, страница НЕ публикуется на сайте.                                                                          | `draft: false`                                                           |
| `publish`           | —                        | boolean                       | Альтернатива `draft`. Некоторые темы используют его.                                                                              | `publish: true`                                                          |
| `date`              | `created`, `publishDate` | дата                          | Дата создания или публикации. Формат: ГГГГ-ММ-ДД.                                                                                 | `date: 2024-06-15`                                                       |
| `modified`          | `lastmod`, `updated`     | дата                          | Дата последнего изменения.                                                                                                        | `modified: 2024-06-20`                                                   |
| `tags`              | `tag`                    | список строк                  | Теги для категоризации страницы, 2–5 штук. Подробнее см. ниже.                                                                    | `tags: [оружие, оптика, настройка]`                                      |
| `aliases`           | `alias`                  | список строк                  | Другие имена страницы. По ним тоже можно будет найти статью.                                                                      | `aliases: [пристрелка, zeroing]`                                         |
| `permalink`         | —                        | строка                        | Постоянная ссылка на страницу. Если указать, URL не изменится даже при переименовании файла.                                      | `permalink: /guides/scope-zeroing`                                       |
| `enableToc`         | —                        | boolean                       | Показывать оглавление страницы (Table of Contents) или нет.                                                                       | `enableToc: true`                                                        |
| `cssclasses`        | `cssclass`               | строка или список             | Дополнительные CSS-классы для стилизации конкретной страницы.                                                                     | `cssclasses: [wide-page, spotlight]`                                     |
| `socialDescription` | —                        | строка                        | Отдельное описание для соцсетей (если нужно отличаться от основного `description`).                                               | `socialDescription: "Секреты пристрелки от чемпионов"`                   |
| `socialImage`       | `image`, `cover`         | строка                        | Путь к картинке для превью в соцсетях.                                                                                            | `socialImage: /static/images/scope-preview.jpg`                          |

### Как правильно работать с тегами

Теги — это инструмент навигации. Сайт автоматически создаёт страницы для каждого тега, где собираются все статьи с этим тегом.

**Синтаксис:**

```yaml
tags:
  - тег1
  - тег2
  - тег3
```

или в одну строку: `tags: [тег1, тег2, тег3]`

#### Правила и рекомендации:

**Иерархия тегов.** Можно использовать слеш `/` для создания вложенности. сайт создаст страницы для каждого уровня.
Пример: `спортсменам/психология` — появятся страницы для тега спортсменам и для тега `спортсменам/психология`.

**Единообразие.** Используй одинаковые формулировки для одних и тех же тем.

- Да: `оружие/пистолет`
- Да: `оружие/винтовка`
- Нет: `пули`, `патроны`, `боеприпасы` (лучше выбрать один вариант, например `снаряжение/патроны`)

**Регистр.** Сайт автоматически приводит теги к нижнему регистру в URL, но в самом файле можно писать как удобно. Пиши в нижнем регистре для единообразия.

**Спецсимволы.** Избегай пробелов и спецсимволов кроме дефиса - и слеша /. Пробелы заменяй на дефисы.

- Да: `звуковой-тренажер`
- Нет: `звуковой тренажер`

**Описание страницы тега.** Можно добавить описание для страницы конкретного тега. Для этого создай файл `content/tags/название-тега.md` с таким содержимым:

```markdown
---
title: "Название раздела тегов"
description: "Описание того, что объединяют эти статьи"
---

Здесь можно написать введение для этого раздела тегов.
```

Например, для тега `оружие/оптика` файл будет `content/tags/оружие/оптика.md`. Для английских тегов — `content/en/tags/…` (теги латиницей).

### Пример полного блока frontmatter

```markdown
---
title: "Звуковой тренажер: полное руководство"
description: "Как использовать звуковой тренажер ShotSCOPE для отработки скоростной стрельбы где угодно"
lang: ru
translationKey: shotscope-sound-trainer
date: 2024-06-01
modified: 2024-06-10
tags:
  - shotscope
  - функции
  - тренажер
  - звуковой-тренажер
  - спортсменам/тренировки
aliases: [метроном, audio-trainer]
enableToc: true
draft: false
---
```

## Шаблоны статей

Скопируй шаблон целиком вместе с frontmatter и замени текст в `{{фигурных скобках}}`. Правила голоса, объёма и разметки — в [`STYLE_GUIDE.md`](STYLE_GUIDE.md). Названия шаблонов идут в порядке таблицы «Типы статей и объём».

### 1. Раздел (`_index.md`)

Вход в папку: что здесь и с чего начать. Объём: 60–200 слов.

```markdown
---
title: "{{Название раздела}}"
description: "Одно предложение до 160 знаков: о чём статья, без повтора заголовка"
lang: ru
translationKey: "{{ключ-перевода}}"
tags: ["{{тег1}}", "{{тег2}}"]
date: "{{ГГГГ-ММ-ДД}}"
modified: "{{ГГГГ-ММ-ДД}}"
---

{{Лид: 1–2 предложения о том, что лежит в этом разделе и кому он нужен.}}

- [[{{путь/к/статье}}|{{Название статьи}}]] — {{одна строка о содержании}}.
- [[{{путь/к/статье}}|{{Название статьи}}]] — {{одна строка о содержании}}.
- [[{{путь/к/статье}}|{{Название статьи}}]] — {{одна строка о содержании}}.
```

## Английская версия

Перевод — та же статья на другом языке с той же структурой. Подробности — в разделе «Переводы» файла [`CONTRIBUTING.md`](CONTRIBUTING.md), правила языка — в [`STYLE_GUIDE.md`](STYLE_GUIDE.md).

1. Скопируй файл в `content/en/…` с английским именем.
2. Поставь `lang: en`, `translationKey` оставь тем же.
3. Заголовки пиши в sentence case: «Sight adjustments».
4. Внутренние ссылки — полным путём: `[[en/ShotSCOPE/FAQ|FAQ]]`.

Пример начала инструкции:

```markdown
---
title: "How to add a weapon"
description: "Add a weapon to your profile so sessions use the right sight adjustments."
lang: en
translationKey: "add-weapon"
tags: ["weapons", "guide"]
date: "2026-10-18"
modified: "2026-10-18"
---

Add a weapon to your profile once, and ShotSCOPE applies its sight adjustments to every session.

## What you need

- The ShotSCOPE app, signed in to your account

## Steps

1. Open **Profile → Weapons**.
2. Tap **Add weapon**.
```
