# Настройки Obsidian для работы с репозиторием

Чтобы всё работало гладко и ваши ссылки не ломались при сборке Quartz, настройте свое хранилище Obsidian строго по этой инструкции.

## 📌 Ключевые требования

> [!warning] Обязательно к выполнению
> Эти настройки критически важны для корректной работы базы знаний. Пожалуйста, следуйте им точно.

## 📂 Открытие хранилища

> [!important] Важно!
> В Obsidian открывайте **папку `content`**, а не корень репозитория. Это гарантирует, что все ссылки будут работать правильно при сборке Quartz.

1. В Obsidian нажмите `File → Open Vault → Open folder as vault`
2. Выберите папку `content` внутри вашего локального репозитория

## ⚙️ Обязательные настройки

1. **Зайдите в Настройки (Settings) → Файлы и ссылки (Files & Links)** и установите:

   | Настройка | Значение | Пояснение |
   |-----------|----------|-----------|
   | `New link format` | **`Shortest path when possible`** | Создает короткие WikiLinks |
   | `Use [[Wikilinks]]` | **✅ ВКЛЮЧИТЬ** | Используем WikiLinks |
   | `Automatically update internal links` | **✅ ВКЛЮЧИТЬ** | Автообновление ссылок при переименовании |
   | `Default location for new attachments` | **`Same folder as current file`** | Изображения сохраняются в ту же папку, что и статья |
   | `Wiki link autocomplete without extension` | **✅ ВКЛЮЧИТЬ** | Автодополнение без указания `.md` |

2. **Настройки → Редактор (Editor):**
   - Включите отображение frontmatter (Show frontmatter)

## 📛 Правила именования файлов

> [!warning] Это обязательно!
> В именах файлов и папок **запрещены пробелы**. Вместо пробела используйте нижнее подчеркивание `_`. Иначе ссылки на файлы перестанут работать.

| ❌ Неправильно | ✅ Правильно |
|----------------|--------------|
| `Звуковой тренажер.md` | `звуковой_тренажер.md` |
| `Мое оружие.md` | `мое_оружие.md` |
| `First Steps.md` | `first_steps.md` |

## 📁 Структура для вложений

Изображения хранятся **в той же папке, что и статья**. При перетаскивании (drag and drop) Obsidian автоматически создает правильный путь.

```markdown
content/
├── ShotSCOPE/
│ ├── Features/
│ │ ├── звуковой_тренажер.md
│ │ ├── звуковой_тренажер_превью.png # картинка рядом со статьей
│ │ └── звуковой_тренажер_схема.png # еще одна картинка
```
